# Web Music Player

A sleek, responsive, and feature-rich web-based music player built with modern HTML5, CSS3, and vanilla JavaScript.

## Features

- **Vinyl Animation**: Dynamic spinning vinyl record artwork when audio is playing.
- **Audio Controls**: Play, pause, skip to previous track, and skip to next track.
- **Interactive Progress Bar**: Real-time elapsed/remaining duration display with draggable seeking capability.
- **Volume Control**: Interactive volume slider with smooth dragging support.
- **Interactive Playlist**: Playlist display showing track titles, artists, and durations, along with active equalizer animations for playing tracks.
- **Keyboard Shortcuts**:
  - `Space`: Play / Pause
  - `ArrowLeft`: Previous track
  - `ArrowRight`: Next track
  - `ArrowUp`: Increase volume
  - `ArrowDown`: Decrease volume

## Tech Stack

- **HTML5**: Semantic layout and HTML5 `<audio>` media element.
- **CSS3**: Modern dark theme UI utilizing CSS variables, Flexbox, custom scrollbars, and keyframe animations.
- **JavaScript (ES6+)**: Vanilla JS DOM manipulation, audio state management, and touch/mouse event handling.

## Getting Started

No build process or installation is required.

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
